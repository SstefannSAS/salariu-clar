# Salariu Clar

Calculator orientativ pentru estimarea salariului net lunar și anual în România, cu ore suplimentare și reguli fiscale selectabile pentru anul 2026.

## Rulare locală

```bash
npm ci
npm run dev
```

## Publicare pe Vercel

Proiectul folosește Vite. Vercel rulează `npm ci` și `npm run build`, apoi publică folderul `dist/client`.

## Limitări

Estimările presupun contract individual de muncă, normă întreagă și condiții normale. Nu includ tichete, beneficii, sporuri speciale, program parțial sau situații fiscale particulare. Verifică fluturașul și regulile aplicabile situației tale.
